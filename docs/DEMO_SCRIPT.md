# Five-minute demo script

Rehearse once in a private window before presenting, so the "Before you start" notice shows and there are no old drafts. Check the OpenRouter key has credit under its spending limit.

**Checklist:** live site opens with the "Demo only" strip · Pricing page loads · Ask Prelegal answers · a download opens.

| Time | Do | Say / expect |
|---|---|---|
| 0:00 | Open the site, read the "Before you start" notice, click **I understand** | "It's a demo of an AI legal-document service. Everything it produces is a watermarked sample." |
| 0:30 | Choose **Mutual Non-Disclosure Agreement** from the top menu | The first question appears; the document panel on the right is empty. |
| 0:45 | Answer: *"Duck LLC, a Delaware LLC"*, then *"The other side is Dogs LLC and we'll use Delaware law."* | Both names and Delaware fill in on the right; only the current question shows. |
| 2:00 | Click **Ask Prelegal**, then **Explain this question** | It explains the question on screen in plain language. |
| 2:30 | Ask: *"We'll need about 10 Cloud Service Agreements this year. What's cheapest?"* | The 12-month plan, $449, versus $990 one at a time; a **View plans and prices** button. Click it. |
| 3:15 | Show the Pricing page, then go back to the draft from **Drafts** | Per-agreement prices, two plans, attorney review. |
| 3:45 | Note above Download: "Free in this demo… $49…". Click **Download** (Word) | `SAMPLE-MNDA-…docx`: letterhead, Key Terms table, numbered terms, SAMPLE watermark on every page. |
| 4:30 | Ask Prelegal: *"Can I sign this with my real client?"* | "No. It's a demo sample…", pointing to a licensed attorney. |
| 4:50 | Toggle **Night mode** | Close on the testing story: automated tests, plus the evaluation pass rate. |
